# ☁️ MilinCloud

**MilinCloud** — минималистичный одностраничный сайт для технологического проекта, который развивает облачную инфраструктуру, сетевые технологии и обслуживание серверных систем.

Сайт сделан как нейтральная корпоративная страница с фокусом на инфраструктуре, доступности и технической зрелости проекта. Его можно положить в каталог веб-сервера и сразу отдавать как статический сайт.

## ✨ Что внутри

- 🌙 **Тёмная современная тема** с глубоким графитово-синим фоном.
- 💎 **Glassmorphism-карточки** с мягкими градиентами и свечением.
- 🧭 **Плавная якорная навигация** по основным разделам страницы.
- 🖥️ **CSS/SVG-иллюстрация инфраструктуры** без внешних изображений и брендов.
- 📊 **Статический статус системы** с зелёными индикаторами работоспособности.
- 📱 **Адаптивная вёрстка** для смартфонов, планшетов и десктопов.
- ♿ **Поддержка prefers-reduced-motion** для пользователей, которые отключают лишние анимации.
- ⚡ **Без сборщиков и зависимостей** — только HTML5, CSS3 и JavaScript.

## 🧩 Структура проекта

```text
.
├── index.html   # Семантическая разметка страницы
├── style.css    # Визуальная система, адаптивность и анимации
└── script.js    # Появление блоков при прокрутке
```

## 🚀 Быстрый запуск

Откройте `index.html` в браузере или запустите локальный статический сервер:

```bash
python3 -m http.server 8080
```

После запуска сайт будет доступен по адресу:

```text
http://127.0.0.1:8080/
```

## 🌐 Публикация через Nginx

Скопируйте файлы проекта в каталог веб-сервера:

```bash
sudo cp index.html style.css script.js /var/www/html/
```

После этого страница готова к отдаче как обычный статический сайт.
